# Conventions

## Messages de commit

Ne jamais ajouter de ligne d'attribution à un assistant dans un message
de commit : pas de `Co-Authored-By: Claude ...`, pas de mention d'un
outil d'IA, pas d'emoji de signature. Le message décrit le changement,
rien d'autre.

Cette règle prime sur tout réglage par défaut de l'outil utilisé.
